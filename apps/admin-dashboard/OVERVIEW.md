# G-Shock Vapes Admin

Internal tool for the distributor's team to run B2B orders placed through the Partner Portal. All amounts are in Kenyan shillings (KES).

- Dashboard: sales, cost of goods, gross and net profit/loss and payments collected for any date range (RRP is never used in P&L)
- Expenses: log, import and export business expenses
- All Orders: New → Awaiting Deposit → Fulfillment → Completed, as a board or list; add orders on behalf of customers
- Record payments and deposits; see Accounts Receivable
- Manage products (cost, selling price, RRP, stock, image upload or link) and customers (phone, contact email, map pin, order count and revenue)
- Every list has Add, Import and Export (.xlsx or .csv, same template); summary tiles, dates, search, sort and view toggles sit in a compact frozen page header; Products has a Categories manager and sorting by every field. Quotes and invoices download as PDF, Excel or Word, list/grid views and frozen headers
- Addresses map and Route plan (best driving order from a start point through chosen customers), manual Google Sheets archive, light/dark mode
